# WM Studios · imágenes para WhatsApp

Páginas públicas con las imágenes de cabecera de los mensajes de WM Studios.
Cada carpeta (por ejemplo `resumen/`) tiene las etiquetas Open Graph para que WhatsApp
muestre la imagen como vista previa cuando el mensaje incluye su enlace.

Se publica con GitHub Pages desde la rama `main`, carpeta raíz.
